# Temitope Adeoye (Frank Topzy) — Portfolio Website

A modern, high-performance portfolio website built with **React**, **TypeScript**, **Vite**, **TailwindCSS**, and **Framer Motion**.

---

## 🌟 Key Features & Recent Updates

### 1. 🎨 Full 3-Way Theme Support (Light, Dark, System)
- **Dark Theme (Default)**: Deep `#111118` charcoal with `#E3DFD8` text, `#1c1c26` cards, and `#E6E49F` gold accents.
- **Light Theme**: Warm `#F8F7F4` ivory with `#1a1a24` text, `#ffffff` cards, and `#A37500` rich amber accents.
- **System Theme**: Automatically synchronizes with the user's OS color scheme preferences.
- **Persistent Selection**: Stores user preferences in `localStorage`.
- **Interactive Navbar Menu**: Dynamic dropdown with active state indicators and outside-click dismissal.

### 2. ⚡ Fast, Fascinating Loading Screen
- Animated multi-tier rotating rings with gold and ivory glow.
- Particle animation with subtle floating effects.
- Dynamic percentage counter with a synchronized progress bar.
- Prevents below-the-fold content flashing during page initialization.

### 3. 🧭 Floating Glassmorphic Navbar & Clean Typography
- Frosted glass effect with `backdrop-blur-md`, theme-adaptive borders, and elevation shadows.
- Logo and navigation icons adapt to the current theme without contrast issues.
- Responsive mobile drawer menu with smooth open/close animations.

### 4. 💼 High-Contrast Work Experience Timeline & Roles
- Typed role titles in the hero section are crisp, fully readable, and animated via `ReactTyped`.
- Timeline cards use theme-adaptive backgrounds (`--card-bg`) and distinct color hierarchies for roles and companies across both themes.

### 5. ✨ Section Demarcator Divider Lines
- Subtle glowing horizontal gradient separators (`::after` pseudo-elements) placed between each section (`Hero`, `About`, `Experience`, `Projects`, `Contact`).

### 6. 📩 Styled Contact Form & Download Resume Buttons
- Premium golden pill-style action buttons with hover glow and active click feedback.
- Clean, consistent form inputs with active focus rings and clear placeholders.
- Web3Forms integration with animated popup status alerts.

### 7. 🦶 Theme-Aware Footer & Back-to-Top Button
- Visible footer layout with star links, copyright details, and tech badges.
- Smooth floating scroll-to-top button that appears when scrolling past the hero fold.

## 🛠️ Tech Stack
- **Framework**: React 18 & Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS & CSS Modules
- **Animations**: Framer Motion
- **Icons**: React Icons & Material-UI Icons
